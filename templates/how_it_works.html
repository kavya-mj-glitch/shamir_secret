How It Works

From file upload to secure key recovery, here is the complete ShardSafe encryption and decryption workflow.

1

Upload File

Drag and drop any file up to 50 MB into the encrypt page. ShardSafe accepts all file types.

2

Generate Encryption Key

A cryptographically secure 256-bit AES key is generated using a random number generator.

3

AES-256-GCM Encryption

Your file is encrypted using AES-256-GCM, which provides both confidentiality and integrity verification. A random 12-byte nonce is generated for each encryption.

4

Split Key with Shamir Secret Sharing

The AES key is converted to a large integer and split into N shares using polynomial interpolation over a prime field (2521 - 1).

5

Download Encrypted Package

The encrypted file (.enc) and all key share files (share_1.txt, share_2.txt, ...) are bundled into a single ZIP download.

6

Recover Key with Threshold

To decrypt, provide at least K of the N shares. The original AES key is mathematically reconstructed using Lagrange interpolation.

7

Decrypt File

The reconstructed key and stored nonce are used to decrypt the file via AES-256-GCM. The integrity tag is verified to ensure the data has not been tampered with.
